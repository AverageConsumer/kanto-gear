# Security

Kanto Gear runs inside Gen1Recomp's mod sandbox. The optional
**Phone / Browser** display mode opens a local, unencrypted connection on
port 8765 so a paired browser on the same network can show Gear.

- Use it only on a private network you trust.
- Do not expose the port to the internet.
- Pairing credentials are single-use and expire after five minutes.

## Reporting a vulnerability

Please report security problems privately through
[GitHub's private vulnerability reporting](https://github.com/AverageConsumer/kanto-gear/security/advisories/new)
instead of a public issue. Include the Kanto Gear and Recomp versions, your
platform and the steps to reproduce. Only the latest release receives fixes.
