## What's new

- Brazilian Portuguese is now available as **Português (BR)** under **Options → Appearance → Language**. Thanks to [Solid One (@leomontenegro6)](https://github.com/leomontenegro6) for contributing the translation, and to Gemini for translation assistance.
- The language selection is saved across restarts. Gear translates its own interface; translated game names and dialogue come from the game or a separate translation mod.

## Fixes

- Redrew accents in all three image fonts so acute and grave accents, circumflexes, tildes and umlaut dots are clear and distinct. Character widths and baselines are preserved, and the large font uses exact 2× pixels for the corrected letters.
- Portuguese labels now keep connecting words in lower case, and compact help text fits its settings panels.

## Requirements

- Gen1Recomp 0.3.93 or newer (mod API 3).

## Install

Import `kanto_gear-4.6.3.zip` below, or update from the
[Mod Index](https://bryanthaboi.github.io/gen1recomp-mod-index/) when the listing
is available. The same ZIP works on Android, Windows and Linux. It includes
no ROM or save.
