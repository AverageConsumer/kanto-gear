## Fixes

- Two-screen mode now returns automatically when the second display becomes available again after closing the lid, taking a screenshot or another temporary display interruption.
- Reconnecting during battle cancels the queued recovery prompt, so it does not appear after the battle ends. An open recovery prompt also closes automatically when the display returns.
- Your saved display preference is preserved. If the second display stays unavailable, the one-screen recovery choices remain available.

## Requirements

- Gen1Recomp 0.3.93 or newer (mod API 3).

## Install

Import `kanto_gear-4.6.1.zip` below, or update from the
[Mod Index](https://bryanthaboi.github.io/gen1recomp-mod-index/) when the listing
is available. The same ZIP works on Android, Windows and Linux. It includes
no ROM or save.
