## Fixes

- Custom translations can now display `Ã`, `Õ`, `ã` and `õ` in Gear's fonts without replacing umlauts. Uppercase move names such as `FERRÃO VENENOSO` now become `Ferrão Venenoso` correctly.
- Expanded the bundled image fonts to include their full shared printable character set, so supported accented letters no longer depend on which characters appear in Gear's built-in translations.
- Translated power and accuracy labels now leave room for their numbers. The compact Japanese accuracy label also fits its field.
- Font fallback now uses a translation font only when it covers the displayed text.

## Requirements

- Gen1Recomp 0.3.93 or newer (mod API 3).

## Install

Import `kanto_gear-4.6.2.zip` below, or update from the
[Mod Index](https://bryanthaboi.github.io/gen1recomp-mod-index/) when the listing
is available. The same ZIP works on Android, Windows and Linux. It includes
no ROM or save.
