## Display settings hotfix

- Existing Gear configurations keep their display mode when upgrading. Keeping the old Separate default without explicitly saving that setting no longer makes an existing configuration look like a new installation.
- An available second display is no longer mistaken for a failed output merely because Gear has not drawn its first frame during startup or loading.
- New configurations still start with game and Gear on one screen. The second-screen confirmation test, missing-output recovery and safe reset defaults remain available.

If 4.5.0 already saved Combined as your display mode, Gear preserves that explicit
value. Open **Settings → System → Display Setup** and confirm two screens once
to restore your preferred layout.

## Requirements and validation

Requires Gen1Recomp 0.3.93 or newer (mod API 3). All 358 Lua fixture cases pass
against the exact official 0.3.96 source, including new migration and startup
regressions. Both regressions fail against the original 4.5.0 code. The user
confirmed on an AYN Thor that the fixed two-screen layout survives a restart.

## Install

Import `kanto_gear-4.5.1.zip` through Recomp's Mods menu. The same ZIP works on
Android, Windows and Linux and includes no ROM or save. The Mod Index listing
is temporarily unavailable while its installed scanner's API 3 support is
updated; see [index PR #333](https://github.com/bryanthaboi/gen1recomp-mod-index/pull/333).

The attached checksum and verification report identify the download and its
exact committed source.
