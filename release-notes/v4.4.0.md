## What's new

- Install the original Pokégear as a Silph Store app in Gold, Silver and Crystal, or PokéNav in Ruby, Sapphire and Emerald. Open the device below and keep walking with the D-pad on the game screen above while using touch controls below. Opening the device through the game's own menu keeps its normal presentation and controls.
- Add optional Home widgets for direct access to Pokégear's clock, map, phone and radio, or PokéNav's Hoenn Map, Condition, Match Call / Trainer's Eyes and Ribbons. The device and its features still need to be unlocked in your game.
- Updated Kanto Gear to Recomp mod API 3, including supported battle controls, content records and per-playthrough Home storage.

## Fixes

- Battle text no longer appears twice in the current message window and the recent-message history. Partial lines, temporary `...` frames and repeated current text no longer become separate history entries.
- Removed the small upper-left shine from Home icon rings in both Light and Dark variants of the Pokégear skin.

## Requirements

- **Gen1Recomp 0.3.93 or newer (mod API 3). Update Recomp before installing this version.**
- Validated against the exact official Gen1Recomp 0.3.95 source. Hosts on 0.3.92 or earlier should keep Kanto Gear 4.3.1 until updated.

## Install

Update from the [Mod Index](https://bryanthaboi.github.io/gen1recomp-mod-index/)
or import `kanto_gear-4.4.0.zip` below. The same ZIP works on Android,
Windows and Linux. It includes no ROM or save.

The attached `.sha256` file checks the download; the verification JSON records
the source commit and every packaged file's hash.

## Validation

317 local test cases passed, including the Phone Display browser tests, along
with 11 release-verifier tests. Pokégear/PokéNav apps and widgets were confirmed
on a handheld; the battle-text fix was checked in a repeatable before/after
render. Enlarged Gen 1/2 Light and Dark previews were inspected.
