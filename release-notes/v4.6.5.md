## What's new

- Turn on **Integer Scaling** under **Options → Display** for whole-pixel enlargement of Gear. Small display areas still show the full interface.
- Choose **Auto**, **Nearest**, **Bilinear**, or **Sharp Bilinear** under **Image Filter**. Auto chooses a filter based on the amount of scaling.
- Gear now localizes Pokémon type names, short type labels, and status badges. Game translation packs can supply their own labels. The Explorer and wild-battle headers also use the localized level prefix.

## Fixes

- Phone Link controls stay above the game image and respond after fullscreen and viewport changes. Phone Link also keeps whole-pixel rendering aligned with the phone's physical pixels.
- Screen Mode and Battle View help is translated, including in Spanish and Brazilian Portuguese. Longer help text scrolls automatically after a reading pause.
- FireRed and other Gen 3 choice buttons display the translated answer without visible color commands. Item descriptions in Gear's action menu reflow correctly when game translations use escaped line breaks.
- Type and status labels are centered inside their badges, and the clock is centered by its visible pixels.

- Brazilian Portuguese has updated wording for Theme, Tools, wild Pokémon, and the Fight and Run buttons. The Explorer uses a shorter label when the full wording would be cut off.

Thanks to [Solid One (@leomontenegro6)](https://github.com/leomontenegro6) for the Brazilian Portuguese updates and for reporting localization issues.

## Requirements

- Gen1Recomp 0.3.93 or newer (mod API 3).
- [Gen1Recomp 0.4.2](https://github.com/bryanthaboi/gen1recomp/releases/tag/v0.4.2) includes native Integer Scaling and Image Filter support for **Separate Screens**.

## Install

Import `kanto_gear-4.6.5.zip` from the release assets. The same ZIP works on Android, Windows, and Linux. It includes no ROM or save.
