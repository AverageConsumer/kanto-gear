# Kanto Gear 3.1.0 — More ways to make Silph Link yours

## New

- **Built-in languages:** English, German, Spanish (Spain) and French, selectable
  in **Settings → Appearance → Language**. Only Kanto Gear's own interface is
  translated. Pokémon, moves, items, locations and original game text stay in
  the language provided by the game.
- **Achievements app:** collect exploration stamps and browse area progress
  across Red, Blue, Yellow, Gold, Silver and Crystal. Track trainers, items and
  hidden items, with location previews in Spoiler mode. Optional or no longer
  available encounters are kept separate from required goals. Install it from
  **Silph Store**; it is not added automatically. Addresses #31.
- **Team View widget:** see all six party members on Home and tap a Pokémon to
  open its details. Add it through Home editing under the Party app's widgets.
- **Home editing hint:** a one-time introduction makes long-press customization
  easier to discover.

## Improved

- **Standard battle view** now follows the original menu layout: a 2×2 action
  menu and vertical move and Party lists, matching native controller navigation.
  All original battle screens remain visible above, including Stats, and their
  normal controls remain intact. Gear and Full Gear keep their existing layouts.
  Addresses #32.
- Move details can be opened from the field Team summary when enabled by the
  research settings.
- Battle button labels sit above the bevel. Home widget status icons and route
  labels, move rows and PC list labels have alignment improvements.
- Fixed a Home widget crash when rendering a fainted Pokémon.

## Updating

Install **kanto_gear-3.1.0.zip**. Android, Windows and Linux use the same mod ZIP;
no custom host build is required. Use a current official Gen1Recomp release.

Disable the old German, Spanish or French Kanto Gear companion packs and select
your language inside Kanto Gear instead. Separate full-game translation mods
are unaffected. Existing Home layouts and settings are retained.

This release includes the earlier settings recovery, empty Home recovery and
Explorer refresh fixes. The Explorer stutter fix from 3.0.2 has now been
confirmed on Discord (#30).
