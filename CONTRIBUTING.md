# Contributing to Kanto Gear

Thanks for your interest in Kanto Gear.

## Report a problem

[Open a bug report](https://github.com/AverageConsumer/kanto-gear/issues/new/choose)
with your game, device, Recomp and Gear versions, display and battle modes,
other active mods and the steps to reproduce it. Screenshots of both screens
and logs are welcome.

## Improve a translation

Use the [translation form](https://github.com/AverageConsumer/kanto-gear/issues/new?template=translation.yml)
for single corrections. To translate larger parts, see
[Translations](DEVELOPMENT.md#translations) in the development guide.

## Code changes

Read the [development guide](DEVELOPMENT.md) for the project map, integration
contracts, tests and package builds. Please open an issue before larger
changes so we can agree on the approach. Keep pull requests focused, run the
tests described in the guide and include before/after screenshots for UI
changes in Gen 1/2 Light and Dark.

Kanto Gear never includes ROMs, saves or extracted game assets. Contributions
must not add them.
